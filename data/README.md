# Reviewed data snapshot

Снимок на 29 сентября 2026 года. Каноническая разметка находится в
[`field_mapping.tsv`](field_mapping.tsv); исходные изображения в `dataset/` не
переименовываются и не переписываются.

| Состояние | Количество |
| --- | ---: |
| Всего real-photo | 100 |
| `confirmed` exact-SKU | 64 |
| `not_in_catalog` | 35 |
| `uncertain` | 1 |
| Подтверждённые SKU, доступные strict gallery | 23 фото |
| Подтверждённые SKU вне strict gallery | 41 фото |
| Уникальные подтверждённые SKU | 45 |

Все 100 решений выполнены одним ревьюером (`single_reviewed`) и остаются в
`split=pool`. Это полезный development pool, но **не финальный test** и не основание
для production-accuracy. Test появится отдельно 1 октября 2026 года.

Проверено автоматически:

- уникальность `query_id`, путей и SHA-256;
- существование и декодирование каждого изображения;
- допустимые статусы и согласованность `label_status ↔ true_slug`;
- наличие каждого подтверждённого slug в полном каталоге;
- отсутствие совпадений real-photo с catalog uploads по имени и SHA-256.

41 подтверждённая фотография относится к товарам, которых нет в текущей
928-SKU strict gallery. Это coverage gap, а не ошибка ручной разметки: текущая
модель физически не может вернуть такие SKU. Не подменяйте их похожими товарами и
не добавляйте сами query-фотографии в gallery перед независимым тестом.

Проверка воспроизводится командой:

```bash
make validate-data
```
