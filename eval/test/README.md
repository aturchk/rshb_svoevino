# Acceptance test drop zone

Официального тестового набора пока нет. Когда он появится 1 октября, положите сюда:

```text
eval/test/
├── images/       исходные изображения без переименования
└── queries.tsv   query_id<TAB>image_path
```

Не добавляйте ответы в репозиторий до окончания оценки и не меняйте модель после
просмотра закрытых примеров. Проверка и последовательный прогон выполняются одной
командой из корня:

```bash
make acceptance-run
```

Результаты и receipts записываются в игнорируемый `work/acceptance/`. Если
организатор выдаст другой путь или endpoint, используйте параметры из
[`eval/README.md`](../README.md).
